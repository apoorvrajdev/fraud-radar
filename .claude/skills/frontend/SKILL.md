# Frontend changes

## Structure

`pages/` (routes) → `hooks/` (one TanStack Query wrapper per endpoint) → `lib/api.ts` (axios) → backend.
`components/{layout,dashboard,transactions,alerts,ui}`. `types/api.ts` mirrors the backend schemas by hand.

## Invariants

- Demo mode branches in exactly one place: `lib/api.ts` swaps in `demoAdapter` (`lib/demoApi.ts`)
  when `VITE_DEMO_MODE=true`. No hook or component checks demo mode to get data.
- Every route the UI calls must resolve in `demoApi.ts`'s `resolveHandler`, and its data must exist in
  the snapshot; an unmatched route throws "Demo adapter has no route".
- Vercel rewrites every path to `index.html`, so a missing snapshot file arrives as HTML with status
  200, not 404. `loadJson` maps a non-JSON response to `DemoNotFoundError` (fix 839eaba) — keep that.
- `frontend/public/demo-data/` is generated by `scripts/export_demo_snapshot.py` from a running
  backend and pinned by `backend/tests/unit/test_demo_snapshot.py`. Never hand-edit it.
- Amounts are displayed through `lib/format.ts` (`formatMoney`, `formatMoneyIn`), which is
  currency-aware; never format money inline.
- After a mutation, update the cache the way `useSubmitAnalystDecision` does: `setQueryData` on
  `["transaction-detail", id]`, invalidate `["transactions"]` and `["alerts"]`.

## Edge cases

Add to this list whenever a bug escapes.

- Loading, empty and error states for every new query
- A detail page reached from every list that links to it, in demo mode too (839eaba)
- Rows in a non-reporting currency, and rows whose FX columns are null
- Deep links surviving a refresh

## Verification

There is no frontend test runner. From `frontend/`:

1. `npx tsc -b`
2. `npx eslint .`
3. `VITE_DEMO_MODE=true npm run build` — the build CI and Vercel ship
4. Behaviour — run it and walk the changed flow with the browser console open. A display-only
   tweak needs the changed view in one mode; anything touching data, routes or state needs both:
   - Live: backend `uv run uvicorn app.main:app --reload --port 8000`, then `npm run dev`
   - Demo: `VITE_DEMO_MODE=true npm run build && npx vite preview` — preview has the same SPA
     fallback as Vercel, so it reproduces missing-snapshot behaviour

If step 4 was not done, the report says so.

## Definition of done

- [ ] tsc, eslint and the demo build green
- [ ] Changed flow exercised in the browser, live and demo — or reported as not verified
- [ ] `types/api.ts` matches the backend schema
- [ ] A new route has a demo handler and snapshot data; the snapshot re-exported, not edited, when the API shape changed
