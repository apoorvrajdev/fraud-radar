# Fraud Radar

AI-powered real-time fraud detection dashboard simulating production fintech
infrastructure.

> Work in progress — Building over 4 days as a portfolio project.

## Stack

- Backend: Python 3.11+, FastAPI, SQLAlchemy, SQLite
- ML: scikit-learn, XGBoost, SHAP
- Frontend: React 18, TypeScript, Vite, Tailwind CSS, shadcn/ui
- Infrastructure: Docker / Podman Compose
