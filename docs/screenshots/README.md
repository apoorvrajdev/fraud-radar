# Screenshots

Drop PNGs here for the README and the architecture doc. Naming
convention so the README links stay stable:

- `01-dashboard.png` — Overview page with KPI tiles, fraud-rate
  line chart, volume sparkline, and country breakdown.
- `02-transactions.png` — Transactions list with a filter or two
  applied (e.g. `decision=REVIEW` or a country filter), showing the
  color-coded decision pills and the "Load more" footer.
- `03-detail-shap.png` — A transaction detail page with the dual
  badge header and the SHAP contributor bars visible. Pick a
  REVIEW row so the analyst form is also on-screen.
- `04-alerts.png` — Alerts queue showing the summary strip
  (pending count, oldest age, score buckets) above the dense table
  with score chips.

Capture from the **live** local stack (not demo mode) so the topbar
shows the green "Live" pulse and the simulator-generated data looks
fresh. 1920×1200 or 1440×900 is plenty; PNG is preferred over JPG
so chart lines stay crisp.
